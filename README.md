# Моя еда

Личное приложение для вкусного и полезного питания: меню на неделю, рецепты, корзина с учётом запасов, дневник питания. Работает на iPhone и компьютере с синхронизацией через Supabase.

Адрес: https://seulhan999-ui.github.io/moya-eda/

В репозитории только код. Личные данные хранятся в Supabase под защитой правил доступа (RLS) и в репозиторий не попадают.

## Разработка

```bash
npm install
npm run dev      # локальный запуск
npm test         # автотесты
npm run build    # сборка
```

Схема базы данных — `supabase/migrations/`.
